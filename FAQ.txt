Security Frequently Asked Questions (FAQ)

Q1. What is SQL Injection?
A. SQL Injection is a vulnerability where attackers insert malicious SQL commands into application inputs to access, modify, or delete database data.
Prevention:
- Use parameterized queries
- Validate input
- Apply least privilege

Q2. What is Cross-Site Scripting (XSS)?
A. XSS occurs when attackers inject malicious scripts into web pages viewed by users.
Prevention:
- Encode output
- Validate input
- Use Content Security Policy (CSP)

Q3. What is Broken Access Control?
A. Broken Access Control allows users to access resources beyond their permissions.
Prevention:
- Enforce authorization checks
- Deny access by default
- Apply least privilege

Q4. What is Multi-Factor Authentication (MFA)?
A. MFA requires users to provide two or more verification factors before accessing an account.
Benefits:
- Improves account security
- Reduces unauthorized access

Q5. Why should parameterized queries be used?
A. Parameterized queries separate SQL code from user input, preventing SQL Injection attacks.

Q6. What is the Principle of Least Privilege?
A. Users and applications should only have the permissions necessary to perform their tasks.

Q7. What is Secure Coding?
A. Secure coding is the practice of developing software that protects against security vulnerabilities and attacks.

Q8. Why is input validation important?
A. Input validation prevents attackers from submitting malicious or unexpected data to an application.

Q9. Why should passwords not be stored in plain text?
A. Plain text passwords can be easily stolen. Passwords should be hashed using BCrypt or Argon2.

Q10. What is Encryption?
A. Encryption converts readable data into unreadable form to protect confidentiality.

Q11. What is SecureRandom?
A. SecureRandom generates cryptographically secure random values used for tokens, passwords, and session IDs.

Q12. What is OWASP?
A. OWASP (Open Worldwide Application Security Project) is a non-profit organization that provides security guidance, tools, and best practices.

Q13. What is Defense in Depth?
A. Defense in Depth uses multiple layers of security controls so that failure of one control does not compromise the entire system.

Q14. Why is HTTPS important?
A. HTTPS encrypts communication between users and servers, protecting sensitive data from interception.

Q15. What are secure coding best practices?
A. Secure coding best practices include:
- Input validation
- Secure authentication
- Parameterized queries
- Encryption
- Secure error handling
- Regular security testing

Q16. What is a Security Misconfiguration?
A. Security Misconfiguration occurs when applications use insecure default settings or improper configurations.

Q17. What is Cryptographic Failure?
A. Cryptographic Failure occurs when weak encryption or poor key management exposes sensitive data.

Q18. Why are software updates important?
A. Updates fix security vulnerabilities and improve system protection against attacks.

Q19. What is a software supply chain attack?
A. A supply chain attack targets third-party libraries, dependencies, or software updates used by an application.

Q20. Why is logging important in security?
A. Logging helps detect attacks, investigate incidents, and maintain audit trails.
